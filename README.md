🏡 Airbnb Performance Analysis Dashboard | Power BI Project
📊 Project Overview

The Airbnb Performance Analysis Dashboard is an interactive Power BI project focused on analyzing global Airbnb data to uncover insights related to listings growth, pricing trends, host behavior, and city-level performance.

This dashboard transforms raw data into actionable insights to help understand how the Airbnb market has evolved over time.

🎯 Objectives
Analyze listing trends over time
Compare city-wise performance
Understand pricing patterns across property types
Evaluate host behavior and trust indicators
Deliver interactive and user-friendly insights
🔍 Key Insights
📈 Rapid growth in listings from 2010–2015, followed by a decline post-2016 (market saturation + COVID impact)
🏙️ Paris has the highest number of listings, followed by New York and Sydney
💰 Hotel rooms are the most expensive, while private rooms are more affordable
⭐ Strong ratings across cities, with Mexico City leading in overall performance
👤 72% hosts are verified and 99% have profile pictures, indicating high trust levels
📊 Majority of hosts own only one property, showing dominance of small-scale hosts
